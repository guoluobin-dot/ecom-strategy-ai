视频提示词里会写"画面主体是「这个」"。写具体商品名，AI 出图才准；不填则按品类给一个通用主体（如"一箱水果"）
品类决定人群底盘与场景库，请尽量写细（如"婴童零食"优于"零食"）
实际成交均价，用于判断付费决策链路长短
例：零添加配方 / 3秒速热 / 一支顶三支
写得越具体，拆解越准。建议覆盖：成分/材质、工艺/技术、使用效果、适用人群与场景
产品主图 最多 3 张
详情页截图 最多 5 张

填写小贴士

  • 品类必填。品类决定人群底盘和场景库，写得越细，报告越准。
  • 卖点详述是核心。AI 会按"功能 / 效果 / 情绪 / 信任 / 差异化"五维重新归类你的卖点。
  • 困境决定策略重心。比如"有播放无转化"会加强信任背书和价格锚点，"播放量低"会强化前 3 秒钩子。
  • 图片可选。上传后会出现在报告顶部，方便团队对照画面拍脚本。
