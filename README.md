# 电商内容策略 AI 智能体

输入品类、产品名、价格带、核心卖点和内容困境，生成**可直接投喂给 AI 视频生成模型**的短视频内容策略。

> 设计目标是"生产提示词"，不是"教你拍视频"。输出里没有机位、没有实拍、没有补拍术语——只有 AI 视频模型能直接消费的画面描述。

## 它做什么

- **策略拆解**：人群、场景、买点三维度拆到极具体，给出"什么人在什么场景下想听到什么"
- **8 组人群 × 场景 × 买点矩阵**：每组都有完整的故事脚本、5 段分镜和视频提示词
- **中英双语提示词**：中文喂可灵/即梦，英文喂 Sora / Runway / Veo
- **四段式提示词**：剧情梗概 / 分镜画面提示 / 整体风格 / 一致性锚点（同一人物、同一商品外观、统一光线）
- **内容类型分工**：剧情 / 痛点 / 场景 / 种草 / 促销 / 证据，8 组不是同一条的 8 个变体
- **黄金三秒规则**：前 3 秒必须让人看出这是卖什么的
- **历史复盘**：拍完把数据填回去，下一轮生成沿用已验证过的组合
- **知识库**：15 篇爆款方法论，可标签筛选
- **图片分析**：上传产品图，多模态大模型会把外观细节写进提示词

## 快速开始

不需要构建，不需要安装依赖。浏览器直接打开 `index.html` 即可。

```bash
# 方式一：双击 index.html
# 方式二：本地起个服务（避免 file:// 对 IndexedDB / file 协议的限制）
npx serve .
# 或
python -m http.server 8000
```

打开后默认用内置规则引擎，功能完整。要生成更贴合产品的内容，在右上角「AI 设置」里填 DeepSeek 或任意 OpenAI 兼容接口的 key。

## 测试

```bash
node test.js
```

535 个断言，覆盖：品类匹配、脚本回收、提示词格式、中英一致性、内容类型分工、复盘解析、导出、XSS 防护等。CI 不做强制要求。

## 项目结构

```
index.html   页面骨架与表单
styles.css   样式
engine.js    本地规则引擎：品类知识库、故事脚本、提示词、策略分工
llm.js       大模型客户端：OpenAI 兼容接口、模型重试、AI 报告归一化
export.js    Markdown / Word 导出
db.js        IndexedDB 图片仓库
insights.js  复盘数据聚合
app.js       交互、渲染、路由、备份、知识库
test.js      测试
```

## 品类

16 个品类（护肤品、零食、小家电、服饰、母婴、家清日化、茶饮咖啡、保健品、宠物用品、数码 3C、美妆、家居百货、办公文具、食品生鲜、汽车用品、户外运动），每个品类有独立的人群、场景、买点、钩子库。

## 数据与隐私

- 报告历史、复盘数据、图片全部存在浏览器本地（`localStorage` + `IndexedDB`）
- 不接云端数据库，不上传
- 只有你填了 API key 并主动点「生成」时，才会把输入内容发到你配置的接口
